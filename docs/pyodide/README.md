# Pyodide 314.0.7

Arquivos oficiais da distribuição `full` de [Pyodide 314.0.7](https://github.com/pyodide/pyodide/releases/tag/314.0.7), obtidos de `https://cdn.jsdelivr.net/pyodide/v314.0.7/full/` em 24 de outubro de 2026: `pyodide.mjs`, `pyodide.asm.mjs`, `pyodide.asm.wasm`, `pyodide-lock.json` e `python_stdlib.zip`. São os arquivos necessários para executar os exemplos do curso no navegador sem serviço externo de execução.
