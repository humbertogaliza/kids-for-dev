# Learning plan

**Age:** 8–12, no previous coding required. **Format:** 11 modules with 42 interactive quests and a final project in four steps. Plan for two or three 25–35 minute sessions per week over roughly 12–16 weeks, adjusting the pace to the child. An adult should closely support younger learners. The same course can be used in Portuguese, English, or Spanish.

## Observable goals

By the end, a child can:

1. Read and change short Python programs using strings, integers, floats, booleans, variables, conditions, loops, functions, lists, dictionaries, tuples, and sets.
2. Describe an algorithm as steps and use code to count, search, compare, and sort.
3. Use numbers and units in simple distance, time, and speed problems.
4. Locate places and order historical events while distinguishing verified facts from invented stories.
5. Read, write, and optionally listen to simple English and Spanish words and phrases; fluency is not expected.
6. Explain an error, try another idea, and ask for a specific hint.
7. Personalise and present a website that changes a question and score when someone clicks.

## Modules and evidence

| Module | Quests | Evidence to look for |
| --- | ---: | --- |
| 1. First steps | 4 | Changes `print` and a variable; predicts the output |
| 2. Data types | 4 | Explains why `"12"` differs from `12`; identifies `str`, `int`, `float`, `bool` |
| 3. Maths in action | 4 | Chooses an operation and uses `if`, `for`, and `def` |
| 4. Data collections | 4 | Looks up items in a list, dictionary, and tuple; explains a set's unique values |
| 5. Coding logic | 4 | Predicts `True` or `False` from comparisons, `and`, `or`, and `not` |
| 6. Building algorithms | 4 | Says steps aloud, then counts, searches, and orders data |
| 7. Around the world | 4 | Uses lists to ask about cities, capitals, and directions |
| 8. Time machine | 4 | Orders years and checks a historical fact with an adult |
| 9. Physics lab | 4 | Uses a simple formula and includes a unit |
| 10. English lab | 3 | Writes and recognises short English words |
| 11. Spanish lab | 3 | Writes and recognises short Spanish words |
| 12. World Explorer | 4 steps | Changes HTML/CSS, adds questions, demonstrates a working score |

## Progress and assessment

After each quest, the child gets feedback and may retry without penalty. A successful run earns a star and suggests the next quest; the menu also allows exploration. Saved stars remain when changing language, while code drafts are separate by language. At the end of each module, ask the child to explain one program and make a small new change. Record **independent**, **with a hint**, or **needs practice**; an explanation matters more than a star count.

After module 6, ask the child to explain a 5–10 line program, describe its steps before running it, and invent a variation. For the final project, use this guide:

| Criterion | Still practising | With help | Can explain and adapt |
| --- | --- | --- | --- |
| Content | Site opens but has no working question | Questions from two subjects work | Questions from six subjects work and facts were checked |
| Interaction | Button does not change the screen | Another question and answer appear | Score works and the child explains why |
| Maths/physics | A number lacks a unit or calculation | Calculation works with guidance | Child explains both calculation and unit |
| Independence | Adult typed most changes | Child edited guided parts | Child made an original change and fixed an error |

For ages **8–9**, read aloud, work in 20–25 minute blocks, and allow paired typing. For ages **10–12**, ask for predictions and second solutions. Avoid rankings between children. Celebrate curiosity, explanations, and persistence. Historical and geographic examples are starting points; check context and sources together. Physics examples use simplified models.
