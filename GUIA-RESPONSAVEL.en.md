# First lesson: today, in 25 minutes

**Prepare (2 min):** open [the course in English](https://humbertogaliza.github.io/kids-for-dev/?lang=en) on a computer or tablet with a keyboard. The first Python download may take a few seconds. Have paper ready. An adult controls any publication.

1. **Invite (3 min):** “What should we tell the computer to say?” Open Quest 1 and read it together.
2. **Explore (6 min):** let the child change the words between quotes and press **Run Python**. Ask what changed and what the quotes might do. Read any error as a clue.
3. **Quest 2 (6 min):** invent a character such as Captain Star. Use an imaginary name, never the child's full name.
4. **Quest 3 (6 min):** ask for a prediction of `4 + 3` before running the code. Change one number and predict again.
5. **Close (2 min):** ask “What is an instruction?” and “What did an error teach us?” Note whether the child worked independently, with a hint, or wants to practise again.

If the child is excited, continue to Quest 4. If tired, stop after any quest. Progress stays in the same browser. The language menu can switch between Portuguese, English, and Spanish; saved stars remain.

## Help without taking over

- Wait a little before intervening. Ask “What did you expect?” and “Which line could we change?”
- Offer one hint at a time. If needed, do the first step together and return the keyboard.
- Celebrate explanations and curiosity rather than speed.
- Ask for one original change after success: a planet name, another number, or a new quiz question.
